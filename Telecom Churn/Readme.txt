The project analyses churn behavior for a telecom provider using a two-stage workflow: a SQL server script performs exploratory data analysis (EDA) by building summary views across demographics, subscribed services, contract/billing attributes and tenure; a companion PowerBI report turns those same dimensions into an interactive four-page dashboard with KPI cards, a tenure gauge and segment-level charts.

From the analysis 26.5% of the customer base has churned (1,869 of 7,043 customers), which is the baseline every segment is compared against.
The report shows major factors that contributed to customer churn and how some factors combined indicate a higher churn risk.
